# Applied Machine Learning Projects

This directory contains 10 end-to-end projects designed to synthesize the mathematical theories and implementations from the textbook into portfolio-quality applications. 

Each project folder contains:
1. **`problem_statement.md`**: The objective and success criteria.
2. **`dataset_setup.py`**: Scripts to fetch and clean the raw data.
3. **`solution.ipynb`**: A complete, step-by-step notebook outlining the methodology, implementation, and evaluation metrics.

## 🟢 Beginner Track
1. **House Price Prediction**: Implement Ridge and LASSO regression to predict continuous housing prices, focusing on feature selection and scaling.
2. **Spam Classifier**: Build a Naive Bayes and Logistic Regression model utilizing TF-IDF textual features.
3. **Customer Segmentation**: Apply k-Means and PCA to group retail customers based on purchasing behavior.

## 🟡 Intermediate Track
4. **Image Classifier using CNN**: Train a ResNet architecture on a visual dataset, utilizing data augmentation and transfer learning.
5. **Sentiment Analysis using Transformers**: Fine-tune a pre-trained BERT sequence classification head for binary sentiment analysis.
6. **Recommendation System**: Build a collaborative filtering engine utilizing matrix factorization (SVD).

## 🔴 Advanced Track
7. **Build GPT from Scratch**: Construct a scaled-down autoregressive Transformer decoder, implementing self-attention and positional encodings entirely from scratch.
8. **Build a RAG Chatbot**: Combine a vector database with an LLM to implement Retrieval-Augmented Generation for document Q&A.
9. **Fine-Tune LLM using LoRA**: Utilize Parameter-Efficient Fine-Tuning (PEFT) to adapt a modern foundational model on consumer hardware.
10. **Vision-Language Retrieval System**: Implement a multi-modal architecture using CLIP embeddings to retrieve images based on text queries.
