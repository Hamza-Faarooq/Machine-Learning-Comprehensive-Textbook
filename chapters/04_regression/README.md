# Chapter 4: Regression - From Simple Lines to Regularised Models

## Chapter Overview
This module explores the foundation of predictive modeling: linear regression. We transition from simple Ordinary Least Squares (OLS) to sophisticated regularised models (Ridge, LASSO, Elastic Net) designed to handle multicollinearity and high-dimensional data.

## Learning Objectives
* Derive the Normal Equations and understand OLS geometrically as an orthogonal projection.
* Implement gradient descent for large-scale regression.
* Apply $\ell_1$ and $\ell_2$ penalties for feature selection and variance reduction.
* Evaluate models using MSE, RMSE, MAE, and $R^2$.

## Concepts Covered
* Ordinary Least Squares (OLS)
* Gradient Descent Optimization
* Ridge Regression ($\ell_2$)
* LASSO Regression ($\ell_1$)
* Polynomial Features
* Bias-Variance Tradeoff

## Connection to Textbook
These implementations map directly to **Chapter 4** of the textbook. The probabilistic derivations, including why Maximum Likelihood Estimation under Gaussian noise yields the squared error loss, are visualized in the accompanying notebooks.
