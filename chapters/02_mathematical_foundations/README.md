# Chapter 2: Mathematical Foundations for Machine Learning

## Chapter Overview
Every machine learning algorithm is ultimately a mathematical object. This chapter builds the essential toolkit required for the rest of the repository, translating linear algebra, multivariate calculus, and probability theory into executable code.

## Learning Objectives
* Manipulate vectors, matrices, and tensors confidently[cite: 1].
* Compute gradients, Jacobians, and Hessians programmatically[cite: 1].
* Implement Principal Component Analysis (PCA) via Singular Value Decomposition (SVD)[cite: 1].
* Understand Maximum Likelihood Estimation (MLE) and Maximum A Posteriori (MAP) estimation[cite: 1].

## Concepts Covered
* Matrix Operations & Eigendecomposition
* Singular Value Decomposition (SVD)
* Shannon Entropy & Kullback-Leibler (KL) Divergence
* Convexity and Jensen's Inequality

## Connection to Textbook
The code explicitly implements the Eckart-Young Theorem for optimal low-rank matrix approximations and computes the Shannon Entropy exactly as defined in Chapter 2 of the text[cite: 1].
